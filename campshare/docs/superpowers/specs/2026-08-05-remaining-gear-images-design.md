# 残りキャンプ道具44件の個別画像

## 目的

Issue #29 の50件程度のキャンプ道具カタログを、各商品を見分けられる個別画像で完成させる。すでに専用画像を持つ照明カテゴリ6件は変更しない。

## 方針

- `V8__seed_additional_gears.sql` にある、照明6件以外の44商品を対象にする。
- 各商品につき1枚、白から淡いグレーの背景に商品単体を配置したカタログ写真風PNGを生成する。
- 商品名を英字ケバブケース化した `gear-<name>.png` を `src/main/resources/static/images/` に保存する。
- 文字、透かし、ブランドロゴ、人物、背景小物を含めない。商品は正面寄り、余白を取り、影は最小限にする。
- 新しいFlywayマイグレーションV11で、対象商品の `image_url` を対応する `/images/gear-<name>.png` に更新する。

## データフロー

`gears.image_url` → `/images/gear-<name>.png` → Spring Bootの静的ファイル配信 → 商品一覧・詳細画面。

## 品質確認

- 画像ファイルが44枚あること。
- V11の更新対象が44件で、V10の照明6件と重複しないこと。
- すべてのURLが存在する静的画像を参照していること。
- SQLの構文と既存マイグレーションの順序を確認すること。

## 非対象

- 商品名、説明、価格、在庫数の変更。
- 照明カテゴリ6商品の再生成やURL変更。
