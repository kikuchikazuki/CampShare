# Local Port 8081 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Configure this local CampShare workspace to run on port 8081 without changing the repository default.

**Architecture:** Add one Spring Boot property to the ignored root-level `application-local.properties`. Preserve all existing local datasource settings and leave tracked application configuration unchanged.

**Tech Stack:** Java 17, Spring Boot 3.5.16, Maven Wrapper, PowerShell

## Global Constraints

- Do not display, replace, or commit existing datasource credentials.
- Preserve every existing line in `application-local.properties`.
- Do not modify `src/main/resources/application.properties` or unrelated working-tree changes.
- The final file must contain exactly one active `server.port=8081` entry.

---

### Task 1: Configure and verify local port 8081

**Files:**
- Modify: `application-local.properties`

**Interfaces:**
- Consumes: Spring Boot's existing `spring.config.import=optional:file:./application-local.properties` setting.
- Produces: A local `server.port` property used during application startup.

- [ ] **Step 1: Verify the configuration is currently absent**

Run:

```powershell
(Select-String -LiteralPath application-local.properties -Pattern '^server\.port=').Count
```

Expected: `0`.

- [ ] **Step 2: Add the local port property**

Append this single line with `apply_patch`, preserving all existing content:

```properties
server.port=8081
```

- [ ] **Step 3: Verify the property and Git isolation**

Run:

```powershell
Select-String -LiteralPath application-local.properties -Pattern '^server\.port=8081$'
git check-ignore application-local.properties
git diff -- src/main/resources/application.properties
```

Expected: exactly one matching property; Git reports `application-local.properties` as ignored; the tracked application configuration has no new port change.

- [ ] **Step 4: Start and probe the application**

Run:

```powershell
$env:MAVEN_USER_HOME="$PWD\.maven-cache"
.\mvnw.cmd spring-boot:run
```

Expected: the startup log contains `Tomcat started on port 8081`; `http://localhost:8081/` returns an HTTP response.

- [ ] **Step 5: Do not commit the local configuration**

Run:

```powershell
git status --short
```

Expected: `application-local.properties` does not appear because it is intentionally ignored.
