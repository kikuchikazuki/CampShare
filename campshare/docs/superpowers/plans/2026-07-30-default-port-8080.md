# 標準ポート8080 実装計画

> **エージェント作業者向け:** 必須サブスキルとして `superpowers:subagent-driven-development`（推奨）または `superpowers:executing-plans` を使用し、この計画をタスク単位で実行すること。進捗はチェックボックス（`- [ ]`）で管理する。

**目的:** CampShareの標準HTTPポートをSpring Boot標準の8080へ戻す。

**構成:** Git管理対象の `application.properties` から8081の上書き設定を削除し、Spring Bootの標準値を利用する。ローカル設定とREADMEは変更しない。

**技術スタック:** Java 17、Spring Boot 3.5.16、Maven Wrapper、PowerShell

## 全体制約

- `server.port=8080` は明記しない。
- `application-local.properties` にポート設定を追加しない。
- READMEの `http://localhost:8080/` は変更しない。
- この作業と無関係な未コミット変更には触れない。

---

### タスク1: 標準ポートを8080へ戻す

**対象ファイル:**
- 変更: `src/main/resources/application.properties:6`
- 確認: `application-local.properties`
- 確認: `README.md`

**インターフェース:**
- 入力: Spring Bootの外部設定解決機構
- 出力: `server.port` の上書きがなく、標準値8080で起動するアプリケーション設定

- [ ] **ステップ1: 現在の不一致を確認する**

実行:

```powershell
Select-String -LiteralPath src/main/resources/application.properties -Pattern '^server\.port=8081$'
Select-String -LiteralPath README.md -Pattern 'http://localhost:8080/'
```

期待結果: 追跡設定から `server.port=8081` が1件、READMEから
`http://localhost:8080/` が1件検出される。

- [ ] **ステップ2: 8081の上書き設定を削除する**

`src/main/resources/application.properties` を次の内容にする。

```properties
spring.application.name=campshare
spring.config.import=optional:file:./application-local.properties
spring.jpa.hibernate.ddl-auto=none
spring.jpa.open-in-view=false
spring.flyway.locations=classpath:db/migration
```

- [ ] **ステップ3: ポート設定とREADMEの整合性を確認する**

実行:

```powershell
(Select-String -LiteralPath src/main/resources/application.properties -Pattern '^server\.port=').Count
(Select-String -LiteralPath application-local.properties -Pattern '^server\.port=').Count
Select-String -LiteralPath README.md -Pattern 'http://localhost:8080/'
```

期待結果: 先頭2件の件数がどちらも `0` で、READMEから
`http://localhost:8080/` が1件検出される。

- [ ] **ステップ4: 全テストを実行する**

実行:

```powershell
$env:MAVEN_USER_HOME="$PWD\.maven-cache"
.\mvnw.cmd test
```

期待結果: `BUILD SUCCESS`、失敗 `0`、エラー `0`。

- [ ] **ステップ5: 対象変更だけをコミットする**

実行:

```powershell
git add src/main/resources/application.properties
git commit -m "chore: restore default port 8080"
```

期待結果: `application.properties` だけを含む新しいコミットが作成される。
