# デフォルトポート8080 実行計画

> **実行方針:** 作業開始時の未コミット設定にあった `server.port=8081` を削除すると `application.properties` はHEADと同一に戻る。このため、設定変更のコミットは作成しない。

**目的:** CampShare を Spring Boot の標準ポート8080で起動する。

**変更方針:** 追跡設定ファイルとローカル設定ファイルに `server.port` を明記せず、Spring Boot の既定値を使用する。READMEは変更しない。

## 受け入れ条件

- [x] `server.port=8080` を明記しない。
- [x] 追跡設定とローカル設定に `server.port` がない。
- [x] READMEの `http://localhost:8080/` は変更しない。
- [x] `application.properties` はHEADと一致する。
- [x] 設定変更のコミットを作成しない。

---

### タスク1: デフォルトポートを8080へ復帰

**対象ファイル:**

- 変更対象: `src/main/resources/application.properties:6`
- 確認対象: `src/main/resources/application-local.properties`
- 確認対象: `README.md`

- [x] **ステップ1: 作業開始時の未コミット設定に8081があったことを確認する**

作業開始時点の未コミット差分と設定内容を確認する。

```powershell
Select-String -LiteralPath src/main/resources/application.properties -Pattern '^server\.port=8081$'
Select-String -LiteralPath README.md -Pattern 'http://localhost:8080/'
```

期待結果: 作業開始時の未コミット設定には `server.port=8081` があり、READMEには `http://localhost:8080/` が記載されている。

- [x] **ステップ2: 8081の明示設定を削除する**

`src/main/resources/application.properties` から `server.port=8081` の行を削除する。`server.port=8080` は追加しない。

- [x] **ステップ3: 設定とREADMEの整合性を確認する**

```powershell
(Select-String -LiteralPath src/main/resources/application.properties -Pattern '^server\.port=').Count
if (Test-Path src/main/resources/application-local.properties) {
  (Select-String -LiteralPath src/main/resources/application-local.properties -Pattern '^server\.port=').Count
}
Select-String -LiteralPath README.md -Pattern 'http://localhost:8080/'
```

期待結果: 追跡設定とローカル設定の `server.port` 件数はいずれも `0` であり、READMEには `http://localhost:8080/` が記載されている。

- [x] **ステップ4: dirty worktree上で全テストを実行する**

既存の未コミット変更を保持した dirty worktree 上で、設定変更との組み合わせを検証する。

```powershell
$env:MAVEN_USER_HOME="$PWD\.maven-cache"
.\mvnw.cmd test
```

期待結果: `BUILD SUCCESS`、終了コード `0`、エラー `0`。

- [x] **ステップ5: 設定差分が消えたことを確認する**

設定コミットは作成しない。`application.properties` の差分が空であり、`git status` から同ファイルが消えたことを確認する。

```powershell
git diff --exit-code -- src/main/resources/application.properties
git status --short -- src/main/resources/application.properties
```

期待結果: `git diff` は空で終了コード `0`、`git status` は何も出力しない。
